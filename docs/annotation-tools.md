# Drawing and photo tools

Tap a tool to use it. Long-press **Pen**, **Highlighter**, **Note**, **Shape**,
**Measure**, or **Polyline** to change its defaults, then choose **Save**.
There is no automatic options popup. Pen starts red and Highlighter starts yellow.

Defaults are stored on this device under the saved project's stable identity and
shared by drawings opened from that project. They survive reopening and app
restarts. A PDF opened separately has its own defaults. These preferences are
local project settings; drawing bundles contain annotation appearance, not the
device's tool preferences.

To change an existing annotation, select **Pan**, tap the annotation, and choose
the **Appearance** palette button. Save applies its color, width, text size, or
shape settings as one undoable change. Cancel leaves it unchanged. Changing an
annotation does not change the tool's defaults. Pinch a selected note to resize
it around its existing center; drag it with one finger to move it.

For measurements, use **Calibrate** to mark a known distance and set the scale.
**Measure** uses two points. **Polyline** adds a point at every tap; **Finish**
saves the combined length as one measurement and **Cancel** discards the draft.

Opening a photo from its pin uses the same annotation toolbar, including Pen,
Highlighter, Note, Shape, Calibrate, Measure, and Polyline. Photo calibration is
specific to that photo. The camera tool is hidden. **Clear photo annotations**
clears that photo's annotations and scale, with Undo available. PDF page
annotations and the attached photo remain intact.

In Pan, hold still on drawing text to select it, extend the highlight using its
handles, then tap **Copy**. A flick continues panning after release; a new touch
stops it. Undo/Redo remain in the main viewer controls.
